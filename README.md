# Student Grade Calculator (Java Console App)

## 📌 Project Description
The **Student Grade Calculator** is a simple Java console-based application that allows users to enter a student's name and marks for different subjects. It calculates the total, average, and grade based on the average score and displays the result in a user-friendly format.

## 🎯 Features
- Input student name and subject marks
- Calculate total and average
- Assign grade based on average
- Option to repeat for multiple students
- Simple, beginner-friendly code

## 🛠️ Technologies Used
- Java (Core)
- Scanner (for user input)
- Conditional statements, loops, and arrays

## 💡 Grading Logic
- A: 90 and above  
- B: 80 - 89  
- C: 70 - 79  
- D: 60 - 69  
- F: Below 60

## 📂 File Structure
```
StudentGradeCalculator/
├── Student.java
├── GradeCalculator.java
```

## ▶️ How to Run
1. Compile both Java files:
   ```
   javac Student.java GradeCalculator.java
   ```
2. Run the main file:
   ```
   java GradeCalculator
   ```

## 📘 Learning Outcomes
- Practice in user input and output
- Implementing simple logic in Java
